### Comet Scenario Framework (WIP)

An early TypeScript package intended to provide reusable scenario primitives and types to build complex Comet simulations.

Status: Under active development. Some files are placeholders.

Planned areas:
- Common environment setup helpers
- Market state snapshot utilities
- Event-driven scenario runners
- Typed events and convenient decoders

See `packages/scenarios` for working example scripts today.
